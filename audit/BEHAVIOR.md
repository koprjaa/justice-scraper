# Reference behavior inventory

All source modules, three command scripts, project metadata, README, license, workflow and tests in the reference were inspected before its removal. Runtime comparisons used `uv run --no-project --with-requirements _python_original/requirements.txt`, adding `--with pytest` for the original tests. The captured parser oracle was executed by a compiled Rust integration-test executable. CLI comparisons executed both real command implementations. No registry website was contacted.

| Component | Observable contract and audit cases |
| --- | --- |
| Range command | IDs 1–1000, six-digit zero padding, 20 concurrent tasks, completion-order output, overwrite CSV, four columns, UTF-8/CRLF, INFO file/console logging, three attempts, 20-second deadline, waits 1/2/4 seconds even after final failure. Local range 1–10 produced exactly the retained CSV fixture in both languages. |
| Batch command | Skip first CSV record, trim first-column IČO, skip exact identifiers already in output, keep new duplicates, ten concurrent jobs, append/flush per result, eight columns, pipe-joined notes, `no_records` for empty financials. Empty/header-only input creates no output; missing input exits 1. Tested empty input, CRLF, BOM, leading blank header, quoted embedded CR, non-ASCII text, resume, invalid IČO, oversized field, corrupt resume data. |
| Downloader | Create text directory before checking input. Missing input exits 0. Empty first header returns silently. Ignore short rows or missing subject/document IDs. Ten session workers, 30-second timeout, listing/detail/download referers and cookies, reject non-200, expired detail and HTML downloads, skip existing files, text-layer extraction with blank-page omission and double-newline page joining. Traversal rejection is deliberately stronger in Rust. |
| CLI presentation | Python ignores arguments; Rust adds side-effect-free help. Missing-input exit codes agree. Rust omits progress bars and tracebacks; message language and diagnostics are documented. |
| Service | Keep Unicode decimal digits, truncate IČO to eight characters; invalid IČO returns an empty result without HTTP. Primary/fallback search, extract subject ID, list documents, select latest period/numeric ID and only one candidate. Prefer XML → XHTML → PDF URL → fallback record. Detail failure and missing attachment notes, current-year fallback, UTC result timestamp and result/record field names are preserved. |
| HTTP | Session headers, random agent from five strings, referers, cookies, redirects, environment proxies disabled. Navigation: one retry on 5xx/network failure, 200 ms backoff, per-client 50 ms limiter. Attachments: 12 seconds, no retries/no limiter. 404 does not retry; HTML returned as file bytes is rejected. Local tests checked status counts, content types, declared Windows-1250, invalid UTF-8, BOM and timeout override. Cookie-IP and decoding policy differences are documented. |
| Normalization | NFD, remove only Mn code points, then lowercase. Preserve Mc/Me. Numeric strings strip Python whitespace, remove spaces/NBSP and folded currency, support parentheses and comma/dot heuristics; reject other characters. JSON scalar inputs have numeric/bool equivalents. Tested ordinary formats, malformed separators, control whitespace, non-ASCII digits, huge numbers and non-finite JSON. |
| Years | Prefer all bracketed years, otherwise word-delimited 19xx/20xx; accept only 1990–current UTC year; maximum wins. Invalid/future brackets do not cause fallback to bare years. Checked filing dates, future dates, Unicode decimal suffixes and combining-mark boundaries. |
| Text financials | Python splitlines separators and strip behavior; ignore blank lines. One keyword match per metric per line, look at next line only if none on same line, magnitude scoring, stable first tie. Confidence is the weakest present figure; contradiction notes reduce it to low and preserve supplied notes. |
| XML | Ignore namespaces in label paths, read text before first element child, discard comments/PIs while joining text, choose highest metric score with first tie. Row year wins. Invalid XML returns no result. Custom entities and deep nesting are explicitly rejected in Rust; reference entity expansion and recursion failure were observed. |
| XHTML | Join visible text nodes with newline, exclude scripts/styles/templates, reuse financial text parsing, preserve row period and empty-content note. Ordinary tables and empty/malformed examples were exercised. HTML parser recovery differences remain documented. |
| PDF/OCR | First eight text-layer pages for standalone financial parsing; OCR below 120 stripped characters, first five pages at scale 2, Czech/English. Service itself only collects PDF URLs. Fixture text agrees exactly. Invalid PDF, unavailable/failed commands and bounded subprocess lifetime are covered; general layout and OCR output are backend-dependent. |
| Rust safety | Reviewed unwrap/index sites: static regex/selectors and internal generated JSON shapes; CSV indexing follows length checks, URL and file errors return results. Confirmed stack overflow in the XML dependency and eliminated it with a preflight depth bound. Invalid duration constructor inputs no longer panic. Blocking PDF extraction is dispatched outside async worker threads. OCR children have deadlines and are killed/reaped. |

The oracle contains 687 inputs with original outputs: normalization, year extraction, numeric parsing, every Python line separator, XML comments/CDATA/PIs/BOM, XHTML, signed/Unicode/80-digit document IDs and a deterministic randomized financial corpus. One explicit expected difference rejects a custom XML entity. Original test-to-Rust mapping is in [python-test-coverage.md](python-test-coverage.md).

This is a finite adversarial audit, not proof of equivalence for every malformed HTML/PDF or operating-system error. The Windows CI configuration is supplied; execution in this workspace was Linux only. OCR was checked through subprocess timeout/error handling, not against a corpus of scanned Czech statements. HTTP uses bounded elapsed-time integration tests; no external network service reliability is assumed.
